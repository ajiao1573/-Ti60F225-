# Ti60 三模式视觉控制台

当前版本支持 **车牌自动识别、豆子计数、零件检测测试**。双击 `start_control.cmd`，网页根据有效串口状态中的任务身份自动切换模式。桌面宽屏采用结果区与右侧参数栏，窄屏自适应堆叠。

三个模式保留独立位流。切换网页标签仅查看该模式；需要加载对应固件后才显示结果和开放控制。车牌旧协议兼容；豆子与零件必须使用新增 UART 的 `output/host_web/Ti60_Demo.bit`。不自动下载开发板、不写启动 Flash。

完整操作、协议与验证说明见 [多模式接入说明](MULTIMODE.md)。以下保留车牌功能的详细说明。

2026-10-30 更新：结果区会直接显示定位/分割/OCR 失败原因和最近抓帧框；新增“恢复默认参数”，并修复参数延迟生效后命令读回状态不更新的问题。新版 EXE 已重新打包。实机排查与验证记录见 [识别排查记录](../docs/RECOGNITION_DEBUG_20261030.md)。

双击 **start_control.cmd**。优先运行随包 `dist/Ti60PlateControl.exe`，自动打开本机浏览器；保持服务窗口运行。也可直接双击 EXE。不需要安装 Python、联网、账户或浏览器扩展。

1. 开发板烧录本工程配套位流，并连接摄像头、HDMI、串口。
2. 页面选择开发板的 COM 口，点击“连接开发板”。串口固定 115200、8N1、无流控。
3. 确认“板端应答正常”后开始控制。**串口已打开不等于板端通信正常。**
4. 网页显示结果、搜索/识别/暂停状态、阈值、帧率、欠载、定位框及拒绝原因；图像只在 HDMI 显示。
5. 按“重新识别”释放结果并继续，按“暂停识别”或“启动识别”控制运行。

窗口中提供的网页地址仅绑定 `127.0.0.1`。默认端口 8765；端口已占用时自动选择其他端口。关闭服务窗口或 Ctrl+C 退出。关闭网页本身不会停止服务或改变板端运行状态。

## 控制说明

- Canny 高阈值范围 0～1023，步进 1。
- 字符二值化偏移范围 −128～127，默认0，对应线协议 ADJ=128。它与边缘高阈值是不同参数。
- 设置收到 ACK 只代表固件接收命令；页面另列实际状态读回。板端在帧边界应用，未读回时不显示“已应用”。
- 只有有效状态包中 OCR 标志有效、状态已锁定，且号码符合 ABC123/AB1234 格式，才显示成功号码。
- 状态超过1.2秒未更新、串口断开或本地服务断开，清除当前成功号码并标记应答异常。最近诊断值如保留，会明确标为旧数据。
- 新增豆子计数和零件检测测试页面，自动跟随各自配套位流；车辆计数、车道线、交通灯未提供。

串口接线需按板卡实际接口与电平连接；工程UART管脚为1.8 V LVCMOS。这里不假定可直接连接任意3.3 V/5 V USB-TTL模块。

## 源码运行与验证

已有 Python 3.10+ 时，也可 `python app.py`。`vendor/` 自带 pySerial 3.5 与原许可证；启动时不会安装或下载依赖。`TI60_PYTHON` 可指定 Python 完整路径。

```
python -m unittest discover -s tests -v
python app.py --no-browser --port 0
```

串口协议以 `../docs/UART_PROTOCOL.md` 为准。测试使用独立假串口，覆盖CRC、分片、错序、坏包、参数范围、状态失效、ACK与读回分离和HTTP控制。测试数据不进入正式页面，正式程序没有演示识别或模拟连接开关。

`build_exe.py` 使用已放在 `build_deps/` 的打包工具构建 EXE，不联网。打包工具仅用于重建，成品运行不需要该目录。运行只需 `dist/Ti60PlateControl.exe`；重新分发时同时保留 `licenses/` 中的第三方许可证。完整源码包保留 `vendor/`。

已验证：17项 Python 协议/串口/HTTP测试通过，独立EXE在本机启动通过；Edge自动化验证中文页面、串口枚举、参数读回、断线清结果及760px布局。详见 `tests/test_results.log`、`tests/browser_smoke.log` 和未连接状态界面截图 `tests/ui_disconnected.png`。浏览器测试的 `ui_fixture.py` 只在测试中注入假串口，不包含于EXE，也不提供正式服务的模拟模式。

开发用浏览器测试需要本机已有 Node.js、Playwright 和 Edge：设置 `NODE_PATH` 指向已有 `node_modules`，`TI60_PYTHON` 指向Python，然后运行 `node tests/browser_smoke.cjs`。该测试不会下载浏览器，也不会连接真实串口。

本机协议/界面测试不能代替开发板上联调。最终识别能力依赖 FPGA 图像链路和拍摄条件。
