# B：中文网页控制与自动车牌识别

当前源码增加本机镜头实测校正：生产位流见 `output/lens_corrected/Ti60_Demo.bit`，最终构建与上板验收记录见 `docs/LENS_CALIBRATION_20261031.md`。在原生1080P抓取车牌区域后、字符分割前校正桶形/切向畸变；校正识别失败时，在同一源帧原始区域重试一次。参数只适用于本次摄像头和读出模式。

摄像头、全帧 Canny/定位、ROI 抓取、DDR 灰度预览及 HDMI 均使用 1920×1080，移除了 848×477 中间缩小图。HDMI 和定位框仍使用原始镜头坐标，未做整屏去畸变。保留未校正原生版 `output/native1080/Ti60_Demo.bit` 和标定抓图诊断版 `output/lens_calibration/Ti60_Demo.bit`；诊断版不执行镜头校正。原生链路详见 `docs/NATIVE1080_20261031.md`。

历史分割改进版保留于 `output/segmentation_v2/`，用于回退对比。分割修改详见 `docs/SEGMENTATION_IMPROVEMENTS_20261031.md`。

本工程面向 Ti60F225。相机采集1920×1080/30fps，原生版直接处理1920×1080，HDMI输出1920×1080/30Hz单幅灰度预览及绿色定位框。网页显示号码、状态、拒绝原因及参数，不传视频。

## 使用

1. 使用本工程新编译的 output/lens_corrected/Ti60_Demo.bit 下载开发板，连接本次已标定的摄像头和HDMI。更换镜头、调焦或改变传感器裁剪模式后需重新标定。
2. 连接板载USB串口，双击 host/start_control.cmd 或 host/dist/Ti60PlateControl.exe。浏览器自动打开中文本地页面。
3. 选择对应COM口并连接：115200、8N1、无流控。确认页面显示板端应答正常。
4. 将一块完整、清晰、接近正视的新西兰普通单行六字符车牌放在画面内。支持ABC123、AB1234。成功后冻结识别帧并显示号码；失败释放并继续搜索。
5. 点击重新识别释放冻结。可调边缘高阈值、字符二值化偏移，或暂停/启动。默认边缘阈值27、字符偏移0。

网页命令确认仅代表进入邮箱，实际参数以读回为准。改变参数会等待当前帧结束后重新搜索。物理按键保留字符偏移调节和双键长按重新识别。采集FPS与Canny接受FPS分别显示，识别冻结时后者为0属于正常状态。

板端UART为1.8V LVCMOS，使用板上串口通道；不要把任意3.3V/5V模块直接接入FPGA管脚。具体协议见 docs/UART_PROTOCOL.md，上位机详细说明见 host/README.md。

## 源码编译

安装 Efinity 2026.1，默认 C:/Efinity/2026.1；其他位置可设置 EFINITY_HOME。将整个工程放在英文路径，运行 start_build.cmd compile，或在IDE打开Ti60_Demo.xml。编译直接使用保存的example_top.v和src，工具integrate_web_b.py仅为开发迁移记录，不需要运行，也不依赖原A/B目录。

上位机EXE离线运行，无需Python。重建上位机见host/README.md。RTL测试使用tools/sim内Icarus，Python图像测试需要Pillow。

## 当前能力与验证范围

原生版使用公共RGB降噪、Canny＋中值及局部连接，关闭整帧历史选峰缓存以满足片上RAM预算。边缘密度定位产生候选框，后续被接受的1920×1080源帧执行动态裁剪和字符识别；冻结图像、定位框和结果使用同一抓帧ID。字符掩码使用灰度填充笔画，并通过白色牌面边界排除外侧暗背景和黑框。

车辆计数、车道线、零件缺陷和交通灯识别为后续规划，当前按钮禁用。

已有仿真覆盖自动定位/裁剪/OCR、镜头映射与同帧回退、冻结与重新识别、串口CRC和跨时钟控制、HDMI缩放及欠载恢复；上位机有协议、HTTP和浏览器测试。已进行JTAG、原生1080P画质及现场镜头标定联调；最新位流的具体验收结果见上述调试文档。模板回归照片和单张手机图重复测试不能作为独立道路识别准确率。
