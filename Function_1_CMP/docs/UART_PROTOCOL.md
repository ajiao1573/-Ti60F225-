# B视觉平台串口协议 V1

115200 baud，8N1，无流控。多字节整数为小端；CRC8多项式0x07，初值0，无反射、无末异或，覆盖VERSION到PAYLOAD。

帧：`A5 5A VERSION(01) SEQ CMD LEN PAYLOAD[LEN] CRC8`。LEN上限48。SEQ由上位机分配，回复使用同SEQ。

请求：01 GET_STATUS，无载荷；10 SET_EDGE_THRESHOLD，u16(0..1023)；11 SET_CHAR_ADJUST，u8(0..255，128为默认)；12 RESCAN，无载荷；13 SET_TASK，u8(目前仅0=车牌)；14 SET_RUN，u8(0暂停，1运行)。

80 ACK：载荷[原CMD，错误码]，0成功、1载荷/参数错误、2不支持的功能/命令、3控制邮箱忙。配置成功ACK表示进入控制邮箱，实际值以随后状态为准。控制值在相机帧边界应用并重新搜索。CRC错误帧丢弃，不回复错误成功。未知任务必须拒绝。

81 STATUS，48字节载荷：

|偏移|内容|
|---|---|
|0|固件主版本=1|
|1|任务ID=0|
|2|状态0相机未就绪/1搜索/2候选/3抓帧/4识别/5已锁定/6暂停|
|3|标志bit0相机ready，1定位框有效，2ROI ready，3LOW，4OVER，5OCR有效，6冻结，7运行|
|4..5|实际边缘高阈值u16|
|6|实际字符ADJ u8（页面显示可用-128..127偏移，发送值+128）|
|7|字符数量|
|8..13|6字节ASCII车牌，无有效结果时仅作诊断，不能显示为成功|
|14|拒绝原因0无/1低对比/2字符溢出/3非六字符/4字符几何/5OCR拒绝|
|15|定位诊断0无候选/1候选有效/2框过小/3失败框冷却|
|16..17|识别/候选框x，坐标范围以40..43的实际处理尺寸为准；原生版为1920×1080|
|18..19|y|
|20..21|width|
|22..23|height|
|24..25|相机输入fps|
|26..27|Canny接受帧fps|
|28..29|显示本帧欠载|
|30..31|显示累计欠载|
|32..35|识别抓取帧ID u32|
|36..37|输入宽1920|
|38..39|输入高1080|
|40..41|实际处理宽，原生版1920（旧版848）|
|42..43|实际处理高，原生版1080（旧版477）|
|44|字符二值参考阈值|
|45|协议版本=1|
|46..47|功能位图u16，目前bit0车牌=1，其他不可用|

首版上位机5Hz轮询状态。串口连接和板端有效应答分开显示；读取失败/断开不得保留绿色成功状态。功能规划：1车辆计数、2车道线、3零件缺陷、4交通灯，当前仅显示规划且不可发切换命令。网页无视频，HDMI为单幅灰度预览+框。

## 可选镜头标定诊断扩展

仅 `host_uart.CALIBRATION_ENABLE=1` 的诊断位流支持；生产校正版默认关闭，返回不支持命令。使用相同帧格式、CRC 和 SEQ，不能与网页同时占有串口。`tools/camera_calibration.py` 会临时断开本地网页串口、抓取后恢复连接。

- `30 CAPTURE`：无载荷，异步抓取下一完整摄像头帧的 320×180 灰度样本；ACK `[30,0]`。上一请求尚未完成时错误3。此扩展不进入普通控制邮箱。
- `31 IMAGE_INFO`：无载荷；应答 `B1`、8字节，依次为 ready:u8、requested:u8、width:u16=320、height:u16=180、bytes:u16=57600，小端。ready 后才可读，完成缓冲保持不变直到再次抓取。
- `32 IMAGE_READ`：载荷 offset:u16，小端，0..57552；应答 `B2`、48字节，为该偏移起始的灰度值。未请求/未完成时 ACK错误3，越界/载荷错误时错误1。

该缩略采样仅用于标定传输，不改变原生1080P识别/显示通路。详见 `docs/LENS_CALIBRATION_20261031.md`。
