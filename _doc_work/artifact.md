# 技术文档填写约定

参考文件为本目录的 技术文档_原始模板.docx，原文件技术文档.docx的逐字节备份。
参考文档为3页、1节，A4纵向，页宽11906、高16838 twip；上/下1440、左/右1800 twip。保留页眉竞赛图标、页眉横线、页脚PAGE域、现有节及关系。
正文采用模板已有宋体与Times New Roman、12磅、1.5倍行距；作品名18磅居中；一级部分标题14磅加粗，二三级标题12磅。标题均为黑色。新增Title样式及第三级标题样式，保留原有样式定义。
按原模板顺序填写摘要和五部分。原占位提示、字数要求和空段替换为正文。保留摘要800字内，1.1至1.3各400字内，1.4及1.5及1.6各200字内，4.1共300字内，4.2共1000字内。参考文献不超过20项。不出现学校名称。
允许正文随内容增长并合理分页，表格宽度不超过正文宽度，跨页表格重复表头，行高自适应。
用户后续明确要求先不添加图片，因此只添加文字和表格，不新增流程图、截图、照片或示意图。模板原有页眉图标保持原状。
来源以实际顶层、核心RTL、最新说明和发布JSON为准，旧五文件夹梳理只作线索。Function_0占设计详解主体。车牌、豆子、零件三模式属于独立位流，Host不切换固件；不宣称四合一或Function_0已接入Host。
编辑仅允许改变document.xml、新增文档样式。其他包部件及关系保持逐字节一致。正文无新增外部超链接，无需新增媒体或关系。
render_docx.py因Windows运行时未提供LibreOffice而失败，已记录FileNotFoundError。改用本机WPS只读打开、ExportAsFixedFormat生成QA PDF，再用依赖包Poppler生成PNG逐页检查。原模板已完成3页渲染和检查。导出工具不保存DOCX，避免改写原包。
