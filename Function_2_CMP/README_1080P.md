## 输出和采集规格

- HDMI 有效画面：1920×1080，完整显示传感器输出的每个像素。
- 时序：水平有效 1920、前沿 88、同步 44、后沿 148、总长 2200；垂直有效 1080、前沿 4、同步 5、后沿 36、总长 1125。
- 保留原工程实际 74.4MHz 像素时钟和 744MHz 串行时钟，显示刷新率约 **30.06Hz**；它不是 1080P60。
- HDMI 编码器输入 HS/VS 为正极性；内部显示及 DDR 帧控制仍使用原有负极性同步。
- OV5640 采集：1920×1080、RGB565、目标 **15fps**，24MHz XVCLK，设计 DVP PCLK 为 84MHz。
- 摄像头帧率低于显示刷新率时，DDR 重复显示最近的完整帧。

资料中的《OV5640 参考手册（包含寄存器说明）(Clock)》v2.1 表 2-1 列出了 1080P 的 DVP 帧率约束，图 2-3 给出时钟树。
当前 8 位 DVP 采用双字节 RGB565，因此按 15fps 配置；未切换到 RAW Bayer 或更改摄像头接口。
表名和端口名可能保留历史命名：`I2C_OV5640_1280720_Config` 仅提供通用 ISP 初始化前缀；`clk_27m` 目前实际输出 24MHz。
相机时钟与帧率均为寄存器设计目标，仍需上板测量确认。

## 完整数据通路

OV5640 原生 1920×1080 RGB565 → 每行 3840 字节、共 1080 行采集 → DDR 四帧缓存
→ 1920×1080 显示读取 → 原始分辨率轮廓 → OSD → HDMI。

没有中心裁成 720P，也没有从 720P 放大。`Sensor_Image_XYCrop` 的源/目标都设置为完整 3840 字节×1080 行。
DDR 每帧读取长度更新为 4,147,200 字节；每个缓存仍为 4,194,304 字节，四帧共占 16MiB。
每帧恰好对应 2025 个 2048 字节 AXI 突发，数据长度与缓存边界均已核对。

轮廓继续使用高斯平滑、阈值分割、开闭运算，以及 `mask AND NOT erode_5x5(mask)`。
红色轮廓在原生 1080P 像素网格上向内占两层像素，直边宽度为两像素。
视频颜色、DE/HS/VS 同步经过行缓存；坐标在处理端从延迟后的同步信号重建。
这样避免逐级存储冗余坐标，将综合 RAM 用量从首次直接扩展的 322 块降为 238 块，同时保留完整 RGB 数据。
视频整体延迟约七行、0.21ms。轮廓只提取候选目标边界，计数仍另外执行面积、尺寸和边界筛选。

计数分析图扩展为 960×540，覆盖整个 1080P 输入的 2×2 抽样。ROI 按原比例扩展为左上角 (96,72)、右下排他边界 (1824,1008)。
面积范围默认 36～11250 个分析像素，最小宽高 5，最大宽高 240；阈值仍为 112，默认浅背景、深色豆子。
这些参数在顶层 `BEAN_*` 区域，更改后需要重新编译。实际目标面积会受到摄像头视场、距离和安装方式影响，需要重新标定。

## K1 和方向

保留 VF-Ti60F225 核心板 K1：N2/GPIOL_P_02，1.8V 输入，低电平按下，约 20ms 消抖。
按一次冻结图像、红色轮廓及该帧计数，分析完成后显示 HOLD；再次按下恢复实时画面。
LED1 立即显示冻结请求。DDR 写入保护及冻结后重新分析一次的逻辑保持原样。

1080P 模式关闭横纵 binning：0x3814/3815=0x11，0x3820=0x46，0x3821=0x06。
保留此前的方向修正；不能使用旧 720P 的 0x3821=0x01，因为其中的 binning 位不适用于原生 1080P。

## 摄像头配置

新表为 `src/cmos_i2c/I2C_OV5640_19201080_Config.v`，共 255 项（索引 0～254），兼容现有 8 位 SCCB 索引。
通用 ISP 索引 0～205 沿用原表，索引 206 提前唤醒，索引 254 再次确保退出待机。
索引 206 原来的 0x5025=0 与复位默认值相同，借用该项以保持总长 255、避免 8 位索引溢出。

| 参数 | 设置 |
|---|---|
| PLL | 0x3034=0x1A、0x3035=0x21、0x3036=0x69、0x3037=0x13、0x3108=0x01 |
| 原生窗口 | (336,434)～(2287,1521)，水平/垂直偏移 (16,4) |
| 输出尺寸 | 0x3808～380B = 07 80 04 38 |
| HTS / VTS | 2500 / 1120 |
| SCLK / 帧率设计值 | 42MHz / (2500×1120) = 15fps |
| RGB565 | 0x4300=0x61、0x501F=0x01 |
| DVP 分频 | 0x460C=0x20、0x3824=0x04（自动匹配输出格式） |
| VSYNC/HREF | 0x4740=0x21，沿用本工程采集极性 |
| 50/60Hz 曝光步长 | 168 / 140，关闭夜间自动降低帧率 |

XVCLK 来自原 `lvds_pll` 的 `clk_27m` 输出，分频由 84 改为 56，约束同步改为 41.6667ns。
HDMI、系统和 DDR 时钟保持当前工程频率，K1 消抖计数不需变化。
