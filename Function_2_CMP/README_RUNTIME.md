## K1 / K2 操作

K1 接 N2 / GPIOL_P_02，K2 接 M2 / GPIOL_N_02；均为 1.8V 低电平有效输入，独立同步和消抖。
短按在松开后执行；菜单内长按会在按住期间执行。

| 状态 | 操作 | 结果 |
|---|---|---|
| 正常显示 | K1 按下并松开 | 冻结 / 恢复实时显示，一次按住只切换一次 |
| 正常显示 | K2 按下并松开 | 进入调参菜单，并请求冻结当前画面 |
| 调参菜单 | K1 短按（不足约 0.5 秒） | 当前参数增加一个 STEP |
| 调参菜单 | K1 按住约 0.5 秒 | 当前参数减少，继续按住每约 0.12 秒重复减少 |
| 调参菜单 | K2 短按（不足约 1 秒） | 切换下一个参数 |
| 调参菜单 | K2 按住约 1 秒 | 立即退出菜单，保持冻结状态；松手不再触发操作 |

退出后短按 K1 恢复实时显示。首次进入菜单默认选择 THR；再次进入保留上次选择的参数。
屏幕提示正常态为 `K1:FREEZE K2:MENU`，菜单为 `K1:+ HOLD:- K2:NEXT 1S:EXIT`。
两键重叠按下时停止后续操作，直到两键都松开；不定义组合键功能。
计时使用同一时钟域中的共享 10ms 使能，长按时间存在消抖及节拍量化误差。
LED1 继续显示冻结请求。

菜单参数依次为：

| 显示标签 | 默认值 | 含义 |
|---|---:|---|
| VIEW | 2 | 0=RAW，1=BINARY，2=RESULT |
| THR | 112 | 0～255 灰度阈值 |
| DARK | 1 | 1=深色目标，0=浅色目标 |
| X0 / Y0 | 96 / 72 | ROI 左上角，原始图像坐标 |
| X1 / Y1 | 1824 / 1008 | ROI 右下排他边界 |
| MINA / MAXA | 36 / 11250 | 分析图上目标面积上下限 |
| MINW / MINH | 5 / 5 | 分析图上的最小宽、高 |
| MAXW / MAXH | 240 / 240 | 分析图上的最大宽、高 |
| STEP | 1 | 调整数值步长，可循环选择 1、8、32、256 |

分析图为 960×540；面积、宽和高参数使用分析图像素。
ROI 使用原始 1920×1080 坐标，始终保持偶数边界，步长至少为 2。
控制器限制 ROI 在图像内、左上小于右下、最小值不超过最大值。
普通数值到达边界后停止增加/减少；VIEW、DARK、STEP 循环切换。
较大范围的面积/ROI 修改可先切到 STEP 选择更大步长。

参数保存在 FPGA 寄存器中，重载或断电后恢复源码默认值。
本版使用现有 K1 和 K2，无需外接串口；未增加串口配置协议。

## 三种视图与框的含义

- **RAW（0）**：去噪后的彩色画面，保留数量、参数和 ROI 显示。
- **BINARY（1）**：全分辨率阈值/ROI 图，目标白、背景黑。该图用于调阈值；实际计数还经过半分辨率多数滤波及连通域筛选。
- **RESULT（2）**：彩色图和红色候选轮廓；冻结帧完成分析后显示通过筛选的绿色矩形框和浅绿色编号。

绿框与数量使用同一次 CCA 的最终根区域，经过相同的面积、尺寸和边界筛选。
编号按每次分析的结果顺序从 1 开始生成，支持 128 个目标。
框从半分辨率坐标映射到原图，并补偿多数滤波的一个分析像素位移；边框宽 2 个原始像素。

绿框和编号在 **HOLD 冻结图像**上显示，确保框与被计数的图像一致。
实时画面继续显示实时红色候选轮廓；恢复实时后撤去旧绿框。
若通过筛选的目标超过 128 个，数量仍按完整分析结果显示，屏幕提示 `BOX LIMIT:128`，只标出前 128 个。

## 参数和结果的一致性

- 菜单写入待生效配置；分析通路只在图像帧边界一次性应用整个配置。
- 改参会使旧计数和候选框失效，并从新的完整帧重新分析；冻结状态也会重新计数。
- 图像阈值、ROI、多数滤波裁剪、CCA 筛选及屏幕 ROI 均使用统一配置。
- OSD 在自身输出帧边界锁存参数和菜单状态，六位十进制显示覆盖原生分析面积范围。
- 绿框收集期间不显示部分结果。计数发布后，框在后续输出帧边界出现；错误、重算和恢复实时均会撤去旧框。
- 标注通路增加 2 个像素时钟，RGB、坐标与 DE/HS/VS 一起延迟；RAM 分组存储保持不变。
